# Fishing Game

Учебный 3D-проект про рыбалку с будущим кооперативным мультиплеером.

## Первый вертикальный срез

1. Передвижение персонажа и камера от третьего лица.
2. Заброс удочки и поплавок.
3. Поклёвка и простое вываживание.
4. Три вида рыб и инвентарь.
5. Сетевая сессия на 2–4 игроков.

## Технические ограничения первой версии

- Godot 4 и GDScript.
- Стилизованная low-poly графика.
- Один небольшой водоём.
- Сначала одиночная версия, затем host/join.

Запуск: откройте `project.godot` в Godot и нажмите F6 или F5.
